Privacy Policy

Last updated: August 1, 2026

🔒 OnFile stores only user-created aliases (e.g. "Visa •1234") — never real card numbers, passwords, or sensitive data. All data stays in your browser via chrome.storage.sync.

Overview

OnFile is a browser extension that helps you remember what's "on file" with each online account — which emails, phone numbers, payment cards, and other items are linked to each site. Think of it as a companion to your password manager for everything except passwords.

We are committed to protecting your privacy. This extension is designed with a zero data collection principle — we never access, read, or transmit any of your data to external servers.

What We Do NOT Collect

Data Type Collected?
Real card numbers, passwords, or secrets No
Personal information (name, email, etc.) No
Browsing history or page content No
Authentication tokens or cookies No
Usage analytics or telemetry No
IP address or geolocation No

What IS Stored (Locally)

Your Records

OnFile stores records you create — each record contains an account nickname, binding items (your own aliases like "Work Gmail" or "Visa •1234"), and optional notes. This data lives entirely in chrome.storage.sync, which is built into your browser and syncs across your devices via your browser account (e.g. Google Account).

Custom Types & Site Groups

Any custom binding types you create (e.g. "Membership", "Address") and site groups are stored in chrome.storage.sync alongside your records.

Important: Aliases Only

OnFile is designed so you only store your own nicknames for items — never the real underlying data. For example, you'd store "Visa •1234" rather than the full card number. The extension does not validate or enforce this, but the UI encourages alias-based entries.

Permissions Explained

Permission Why We Need It
storage To save and sync your records across devices using chrome.storage.sync.
activeTab To detect the domain of the currently active tab so we can show matching records.
tabs To update the badge count (number of records) on the extension icon for the active tab.

Third-Party Services

OnFile does not use any third-party analytics, tracking, advertising, or data processing services.

The only external request the extension makes is loading site favicons from google.com/s2/favicons to display website icons in the UI. No user data is sent in these requests.

No External Servers

OnFile does not operate any backend servers. There is no server to send data to. All data processing runs locally in your browser. Data syncing is handled entirely by Chrome's built-in sync infrastructure.

Children's Privacy

This extension is not directed at children under the age of 13. We do not knowingly collect any information from children.

Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected on this page with an updated "Last updated" date. Since we do not collect any user data, material changes are unlikely.
